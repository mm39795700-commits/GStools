# 🦁 GStools Combat Equipment - متجر النخبة لفنون القتال

منصة تجارة إلكترونية متكاملة، تفاعلية وعالية الأداء مخصصة لعلامة معدات وأوقية الفنون القتالية **GStools**. مصممة بهوية داكنة شرسة مستوحاة من شعار الأسد وقفازات النزال الذهبية والفولاذ.

---

## 🚀 كيفية تشغيل المتجر

يمكن تشغيل المتجر بطريقتين:

### 1. التشغيل المباشر (Direct In-Browser)
- افتح ملف `index.html` مباشرة بالنقر المزدوج في أي متصفح (Chrome, Edge, Firefox, Safari).

### 2. التشغيل عبر خادم محلي (Local Server)
```bash
node server.js
```
ثم توجه إلى: `http://localhost:3000`

## 🥊 الأقسام والمعدات المتاحة
1. **الكل (All Products)**: استعراض شامل لكافة المعدات مع فلترة وبحث حي.
2. **أوقية اليد (Hand Wraps & Gloves)**: قفازات ملاكمة النمر الذهبي، قفازات MMA، وأربطة اليد القطنية 4.5م.
3. **أوقية الرجل (Shin Guards)**: واقيات قصبة الساق Titan Shield، واقيات المواي تاي الكربونية، ودعامات الكاحل.
4. **أوقية الفم (Mouthguards)**: واقيات أسنان بتقنية الغلي والعض (Boil & Bite) مع علب تعقيم.
5. **أوقية الرأس (Headgear)**: خوذات نزال احترافية تغطية 360°، خوذات سبارينغ مفتوحة، وخوذات بمصد أمامي مصفح للأنف.

## 💬 نظام الطلب المباشر عبر واتساب (WhatsApp Checkout)
- عند اختيار المنتجات وإضافتها للسلة، يضغط العميل على **"إتمام الطلب عبر واتساب"**.
- يدخل العميل اسمه، هاتفه، مدينته، وعنوانه بالتفصيل.
- يُنشئ النظام تلقائياً رسالة واتساب منسقة باحترافية كاملة مع الأيقونات والأسعار وأكواد الخصم والتفاصيل، ويتم توجيه العميل فوراً إلى رقم صاحب المتجر عبر رابط `https://wa.me/...`.
- يُسجل الطلب تلقائياً داخل **لوحة تحكم الإدارة المحلية**.

## 🔒 لوحة تحكم الإدارة الخفية (Secret Admin Dashboard)

### طرق الدخول السري:
1. **اختصار لوحة المفاتيح:** اضغط `Ctrl + Alt + A` في أي مكان بالصفحة.
2. **النقر السري:** انقر **5 مرات متتالية** على رمز شعار GStools الصغير في الفوتر (أسفل يمين الصفحة).
3. **عبر الرابط:** كتابة الهاش `#admin-gs` في شريط العنوان أو الضغط على الرابط السري في الفوتر.

### رمز الحماية (PIN Code):
- الرمز الافتراضي للدخول: `1234` (يمكن تغييره من تبويب الإعدادات).

### مميزات لوحة الإدارة:
- **إدارة المنتجات (CRUD):** إضافة منتجات جديدة، تعديل الأسعار، تغيير الصور، تعديل المقاسات، وحذف المنتجات.
- **سجل الطلبات (Orders Tracker):** متابعة كافة الطلبات المرسلة من الموقع وتغيير حالتها (*جديد* / *تم التواصل* / *تم الشحن* / *مكتمل*).
- **إعدادات المتجر:** إمكانية تغيير **رقم الواتساب لاستقبال الطلبات** والعملة ورمز الـ PIN في أي وقت دون تعديل الكود.
- **حفظ دائم:** جميع التعديلات تُحفظ في الـ `localStorage` للمتصفح وتستمر عبر إعادة تحميل الصفحة، مع زر استعادة الكتالوج الأصلي وزر تصدير نسخة احتياطية (JSON).
